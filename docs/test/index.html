Zwei getrennte Prüfungen: die Filter-Engine und die installierte Safari-Erweiterung.

Engine Self-Test

Diese Prüfung führt alle Fälle des gemeinsamen Testkorpus mit ihren jeweiligen Einstellungen aus. Sie benötigt keine installierte Erweiterung.

Tests werden geladen …

Safari Live-Test

Die folgenden sichtbaren Texte kann die Safari-Erweiterung mit ihren normalen Standardeinstellungen direkt auf dieser Seite verändern. Anders als der Engine-Test hängt dieses Ergebnis von deinen Safari-Einstellungen ab.

  • Mitarbeiter*innen
  • Nutzer:in
  • Kolleg_innen
  • ÄrztInnen
  • Bürgerinnen und Bürger
  • Mit den Ärzt:innen wurde gesprochen.

Warte auf die Safari-Erweiterung …
